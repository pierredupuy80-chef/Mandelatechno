Chaîne de fonctionnement

Le périphérique d'entrée (clavier)
Description détaillée :

Vous appuyez sur la touche « 2 ». Le clavier transforme ce geste en un signal électrique, puis en une information binaire que l'ordinateur sait lire. Il ne calcule rien : il transmet.

→
Le bus de données
Description détaillée :

L'information part du clavier vers la carte mère par un câble, puis circule sur les bus. Le bus est la route commune à tous les composants : il ne traite pas l'information, il la transporte.

→
Le processeur
Description détaillée :

Il lit l'instruction, comprend que l'on demande une addition, prend les deux nombres et calcule le résultat. Il travaille à plusieurs milliards d'opérations par seconde, mais une seule instruction à la fois par cœur.

→
La mémoire vive (RAM)
Description détaillée :

Pendant tout le calcul, le programme en cours et les nombres à additionner sont rangés dans la mémoire vive. C'est l'établi du processeur : plus il est grand, plus on peut traiter de choses en même temps.

→
La carte graphique
Description détaillée :

Le résultat doit devenir des pixels. La carte graphique compose l'image de l'écran, puis l'envoie par le câble vidéo. Sur un poste de bureautique, cette fonction est souvent intégrée.

→
L'écran
Description détaillée :

Périphérique de sortie : il affiche les pixels reçus. Il n'invente rien et ne calcule rien : il montre ce que la carte graphique lui envoie.

📚 Pour aller plus loin : le principe du SWAP

SWAP veut dire « échange ». Quand la mémoire vive est pleine, le système d'exploitation ne peut plus garder toutes les données à sa disposition : il en déplace une partie dans une zone réservée du disque, le fichier d'échange (on dit aussi mémoire virtuelle), pour libérer de la place.

Quand ces données redeviennent utiles, il faut les relire sur le disque puis les recopier en mémoire vive, et ce va-et-vient recommence sans arrêt tant que la mémoire manque. C'est lui qui fait « gratter » le disque et qui retarde la souris.

Or le disque est des milliers de fois plus lent que la mémoire vive : plus la mémoire vive est petite, plus le SWAP travaille et plus le poste attend. Ajouter une barrette de mémoire vive fait donc cesser l'échange, au lieu de l'accélérer.

Sur un disque SSD, l'échange est plus rapide que sur un disque dur, mais il reste bien plus lent que la mémoire vive : le SSD atténue le ralentissement, il ne le supprime pas.

    📚 Synthèse de l'activité

    Voici les points clés à retenir de cette activité. Ces fiches constituent la conclusion de votre parcours d'apprentissage.

    📖 Les composants et leur rôle (N1 - Connaissance)

    Processeur :

    Composant qui exécute les instructions et effectue les calculs.

    Mémoire vive (RAM) :

    Mémoire de travail rapide mais volatile : son contenu s'efface hors tension.

    Disque dur ou SSD :

    Mémoire de masse qui conserve fichiers et programmes sans alimentation.

    Carte mère et bus de données :

    La carte mère supporte et relie les composants ; les bus transportent les informations entre eux.

    Alimentation et carte graphique :

    L'alimentation fournit l'énergie ; la carte graphique calcule l'image envoyée à l'écran.

    📖 Le trajet de l'information (N2 - Compréhension)

    Entrée → bus → traitement → mémoire vive → sortie :

    Une information entre par le périphérique, circule sur les bus, est traitée par le processeur avec les données rangées en mémoire vive, puis ressort sous forme d'image.

    Deux réseaux distincts : information et énergie :

    Les bus transportent les informations, l'alimentation transporte l'énergie. Un poste peut être alimenté sans rien afficher : l'énergie arrive, l'information non.

    📖 Diagnostiquer une lenteur (N3 - Application)

    Lire les mesures avant de démonter :

    Le gestionnaire des tâches donne l'occupation du processeur et de la mémoire vive : il désigne le composant saturé avant toute intervention.

    Suivre l'indice, pas l'intuition :

    Un disque qui gratte sans arrêt alors que la mémoire est pleine ne signale pas un disque en panne : c'est le système qui compense le manque de mémoire.

    📖 Choisir un poste (N4 - Création)

    Partir du besoin réel :

    Les logiciels réellement utilisés déterminent la mémoire nécessaire : surdimensionner coûte cher, sous-dimensionner fait perdre des séances.

    Comparer avec des chiffres, justifier avec des raisons :

    Les fiches techniques se lisent ligne par ligne ; la justification cite deux valeurs et dit à quoi l'on renonce.
