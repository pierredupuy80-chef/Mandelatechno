Rappel — la chaîne d’information

Un objet qui traite des informations suit toujours le même trajet : il acquiert, il traite, il communique — dans les trois séquences de la période.

1. Acquérir

Un capteur ou un périphérique d’entrée (souris, clavier, webcam) transforme un geste, une lumière ou une touche en information.

→

2. Traiter

L’unité de traitement exécute le programme : le processeur calcule et décide, la mémoire vive garde les données du travail en cours.

→

3. Communiquer

Un émetteur-récepteur transmet l’information : carte réseau, câble Ethernet ou Wi-Fi, jusqu’à un autre terminal ou un serveur.

Acquérir → traiter → communiquer : c’est la chaîne d’information. Elle transporte des informations, jamais de l’énergie.

La chaîne d’énergie — à ne pas confondre avec elle

Alimenter (secteur, batterie) → distribuer (alimentation, relais) → convertir (moteur, LED, haut-parleur) → transmettre (roue, son). L’alimentation apporte l’énergie, les bus transportent les informations : un poste alimenté peut n’afficher aucune image.

Trois applications concrètes

Le poste — clavier (acquérir) → bus → processeur + mémoire vive (traiter) → carte graphique → écran (communiquer).

Le réseau — terminal → carte réseau → commutateur → routeur → serveur.

La souris — mouvement ou clic → capteur → information → poste → curseur.

Le vocabulaire exact

information — ce qui se transmet : un geste, une mesure, une image.

donnée — une information mise en forme pour être stockée ou calculée.

capteur — composant qui transforme un phénomène physique en information.

actionneur — composant qui transforme une information en action (moteur, LED).

chaîne d’information — acquérir → traiter → communiquer.

chaîne d’énergie — alimenter → distribuer → convertir → transmettre.

terminal — appareil relié au réseau : poste, tablette, imprimante.

commutateur — boîtier qui relie les terminaux d’un même réseau local.

routeur — appareil qui relie deux réseaux et choisit la route des données.

serveur — ordinateur qui met des fichiers à disposition du réseau.

adresse IP — numéro unique d’un appareil : quatre nombres de 0 à 255.
