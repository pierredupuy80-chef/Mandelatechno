N1 — Les types d'apprentissage de l'IA Mémoriser

Objectif : Découvrir les trois grands types d'apprentissage en IA à travers des mini-simulations visuelles. Chaque onglet présente un type, une visualisation interactive et un quiz de vérification.

Apprentissage supervisé : traduction FR→EN

L'IA apprend à partir de paires de phrases étiquetées (français → anglais). Elle cherche la frontière qui sépare les catégories.

Salutations Questions Affirmations --- Frontière de décision
Points affichés : 0/30 · Frontière tracée : Non

Ce que vous observez

  1. Des points colorés apparaissent : chacun est une phrase française étiquetée par un humain.
  2. L'IA trace une frontière pour séparer les catégories.
  3. Quand une nouvelle phrase arrive, l'IA regarde de quel côté elle tombe.

Définition : L'apprentissage supervisé utilise des données étiquetées (la bonne réponse est connue) pour entraîner le modèle à classer ou prédire.

Apprentissage non supervisé : regroupement de messages

Les messages de LexIA ne sont pas étiquetés. L'IA doit trouver seule des groupes (clusters).

Messages non étiquetés ✦ Centre de cluster Couleur = groupe trouvé
Nombre de clusters (k) = 3
Itérations : 0 · Phase : Initialisation

Ce que vous observez

  1. Tous les points sont gris : aucune étiquette.
  2. Cliquez « Étape » plusieurs fois : les centres ✦ se déplacent, les points changent de couleur.
  3. L'IA regroupe les messages qui se ressemblent sans savoir ce qu'ils signifient.

Définition : L'apprentissage non supervisé trouve des structures cachées dans des données sans étiquettes.

Apprentissage par renforcement : agent et récompenses

Un agent essaie des actions et reçoit des récompenses (+ ou −). Il apprend par essais-erreurs.

Récompense moyenne Optimum possible Épisode : 0
Épisodes : 0 · Moyenne : —/10

Ce que vous observez

  1. Au début, l'agent agit au hasard : la courbe bleue est basse et instable.
  2. Après beaucoup d'épisodes, il découvre les meilleures actions : la courbe monte.
  3. Personne ne lui a montré la bonne réponse : il a appris uniquement par récompenses.

Définition : L'apprentissage par renforcement utilise un système de récompenses/pénalités après chaque action pour guider l'agent vers le meilleur comportement.

N3 — Laboratoire des biais Appliquer · Analyser

⚠ Définition du biais : Un biais en IA est une erreur systématique causée par des données d'entraînement non représentatives ou des préjugés humains intégrés dans le système. L'IA reproduit et amplifie les déséquilibres présents dans ses données.
Objectif : Expérimenter 3 scénarios de biais dans LexIA. Pour chacun : ajustez les données, testez l'IA, observez le biais, puis proposez une correction et retestez.

Répartition des données d'entraînement

Anglais formel Français familier Autres langues
% de français familier dans les données = 10%

Scénario A — Traduction biaisée

Les textes d'entraînement de LexIA sont à 90 % en anglais formel. Quand un élève écrit « Wesh ça va ? » en français familier, l'IA produit une traduction absurde.

  1. Observez la répartition actuelle (slider à 10 %).
  2. Cliquez « Tester l'IA » pour voir le résultat biaisé.
  3. Augmentez le slider pour ajouter du français familier.
  4. Cliquez « Appliquer la correction » puis retestez.

Scénario B — Filtrage injuste

Les mots-clés du filtre ont été entraînés sur un corpus majoritairement masculin. Résultat : des messages normaux écrits par des filles sont bloqués comme « inappropriés ».

  1. Testez avec le corpus actuel (15 % féminin).
  2. Observez combien de messages féminins sont bloqués à tort.
  3. Diversifiez le corpus puis retestez.

Trace écrite à recopier

L'IA dans notre poche transforme notre quotidien, mais elle n'est pas neutre.

  • Supervisé : données étiquetées → classer, traduire, filtrer.
  • Non supervisé : données brutes → regrouper, découvrir des patterns.
  • Renforcement : récompenses → agir, s'adapter.
  • Un biais est une erreur systématique due à des données non représentatives.
  • Pour limiter les biais : diversifier les données, contrôle humain, tests d'équité.
  • L'IA est un outil créé par des humains : la responsabilité reste humaine.
