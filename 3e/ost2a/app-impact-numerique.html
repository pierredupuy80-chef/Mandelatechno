    🔑 Ce qu'il faut retenir

    1. Le numérique transforme tous les secteurs : santé, éducation, agriculture, industrie, commerce.
    2. La chaîne d'information suit toujours le cycle : Acquérir → Traiter → Communiquer → Stocker.
    3. L'impact environnemental est réel : fabrication des appareils, consommation électrique, centres de données.
    4. Un usage responsable est possible : allonger la durée de vie, réduire le streaming, privilégier le reconditionné.
    5. Les métiers évoluent : certains disparaissent, d'autres se créent, tous se transforment.
